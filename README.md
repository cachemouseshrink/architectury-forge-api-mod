# Architectury API — Multiplatform Framework

[![Download Latest](https://img.shields.io/github/v/release/cachemouseshrink/architectury-forge-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/cachemouseshrink/architectury-forge-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A modding framework that allows mod developers to write one codebase for both Forge and Fabric.

![Architectury API — Multiplatform Framework Preview](https://cdn.modrinth.com/data/lhGA9TYQ/05fe3a61c28faaccaec3533b92e1b321edde7bf6_96.webp)

## Features

- Shared API layer across Forge, NeoForge, and Fabric
- Required dependency for hundreds of popular mods
- Provides unified event hooks and registry abstraction
- Faster updates across mod loaders
- Used by Waystones, Farmer's Delight, and more

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
